# قعدة 90

أداة من عائلة «تخطيط وتنظيم» بمشروع **صار بدها قعدة**، إعداد م. إياد حلوبي.
بتساعد الشخص يبني عادة إيجابية أو يترك عادة سلبية خلال 90 يوم، على نظرية المناطق:
الراحة ← التوتر والخوف (حتى 21) ← التأقلم (حتى 40) ← العادة (حتى 90) ← راحة جديدة.

## الملفات
- `public/index.html` التطبيق كامل
- `public/sw.js` و `manifest.webmanifest` للتنزيل كتطبيق والعمل بلا نت
- `public/fonts` الخطوط محلية
- `server.js` سيرفر Express بسيط مع إحصائيات على `/stats`
- `render.yaml` إعدادات النشر على Render

## التشغيل محلياً
```
npm install
npm start
```
وافتح http://localhost:3000

## النشر
1. ارفع المجلد على مستودع GitHub جديد.
2. على Render: New → Blueprint واختار المستودع، بيقرأ `render.yaml` لحاله.

## الشراكة والحفظ
- كل شخص بيعرّف عن حاله باسمه وشب/صبية، والجهاز بياخد رمز سري محفوظ عليه.
- الشراكة بدعوة لشخص واحد: رابط + رمز من 5 أحرف (أو QR فيه الاتنين)، بتنتهي بعد 7 أيام، وبتنقفل بعد 5 محاولات غلط.
- كل عادة لحد 8 شركاء، وكل شخص لحد 3 عادات.
- المعطيات محفوظة بملف `data/db.json` على السيرفر.

**مهم بالخطة المجانية:** Render بيمسح الملفات مع كل نشر أو إعادة تشغيل، فبتنمسح الحسابات والشراكات. التطبيق بيحفظ عادات كل شخص على جهازه وبيرجّع يرفعها لحاله، بس الشراكات بتحتاج دعوة من جديد.
للحفظ الدائم: انقل الخدمة لخطة Starter وفعّل القرص من `render.yaml` (الأسطر المعلّقة).

إحصائيات على `/stats`.
